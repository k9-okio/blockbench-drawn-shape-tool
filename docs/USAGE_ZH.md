# Blockbench 手绘形状生成器

## 安装

1. 打开 Blockbench 5.2.2。
2. 进入 `文件 → 插件`。
3. 点击 `从文件加载插件`（Load Plugin from File）。
4. 选择 `drawn_shape_tool.js`。
5. 在顶部 `工具` 菜单中点击 `手绘形状生成器`。

插件文件名必须保持为 `drawn_shape_tool.js`。

## 使用

1. 在网格中按住鼠标拖动，开始自由画线。松开鼠标只结束当前一笔，不会自动连接起点和终点。
2. 继续绘制，直到最后一笔画回起点；也可以点击 `闭合轮廓`，手动连接当前终点与起点。轮廓闭合后才会填充和生成。
3. 选择生成方式：
   - `小方块`：生成可编辑立方体，适用于 Java Block/Item、Bedrock 和支持方块的项目。
   - `纯三角形（3 点）`：依次点击三个角点，生成不应用圆润处理的三角形。`Z 尺寸 / 厚度` 为 0 时是单面，大于 0 时生成 Z 尺寸可调的三角柱。
   - `厚三角网格`：生成封闭、可设置厚度的三角面网格，适用于 `Generic Model / Free Model`。
   - `方块 + 三角形（混合）`：默认只生成一整块平滑三角外壳；勾选 `混合模式保留内部方块` 后，才会额外加入内部方块。
4. 设置格子大小、厚度、绘制平面、模型坐标中心和 `圆润程度`。推荐使用“轻度圆润”。
5. 点击 `生成形状`。生成内容会放在新建的 `drawn_*_shape_*` 组中。

混合模式默认不生成内部方块，所以不会出现额外的方块凸起。需要方块体积时再手动勾选 `混合模式保留内部方块`；内部方块会稍微缩进外壳，避免共面闪烁。

三角外壳的前后填充会按轮廓内部逐格切成连续三角面，不依赖一次完成复杂凹多边形封口。因此开启弯曲后，内部仍会被完整填充，且不会额外生成方块。

`圆润程度` 会同时圆化二维轮廓和前后面边缘。关闭时保留原始锐角，轻度适合多数手绘线条，中高等级适合圆形或有机形状。

纯三角形模式会禁用圆润设置，以保证三个角保持笔直、不会变成弧形。

## Z 位置与整组移动

`生成位置（整组 X / Y / Z）` 中的 Z 用来设置整个生成模型的前后位置。纯三角形的 Z 尺寸为 0 时是可移动的单面；把 `Z 尺寸 / 厚度` 设为大于 0 后，会生成能直接调整 Z 尺寸的三角柱。

生成完成后会自动选中整组。组枢轴放在生成模型的包围盒中心；使用移动工具或变换控件拖动时，只会影响这组新模型，不会修改其他已有组。

## 左右对称

勾选 `左右对称（只画一半）` 后，只需要在画布中心线右侧画轮廓。插件会把靠近中心线的端点吸附到中轴，并在闭合后自动生成左侧镜像。

对称会同时作用于方块填充、三角外壳和纯三角形模式。开启对称后再使用弯曲选择，弯曲区域也会自动左右镜像。

即使弯曲选区是在开启对称前绘制的，启用对称后也会自动把弯曲列镜像到另一侧，避免左右深度不同或中缝被拉开。靠近中心线 1 格内的端点会自动吸附到中轴。

对称三角外壳只生成右侧一套网格，再把同一套顶点和三角连接关系精确镜像到左侧，因此左右不会再出现不同的三角拓扑或填充空洞。

## 局部弯曲

1. 先画好并闭合轮廓。
2. 设置 `弯曲幅度（沿 Z）`，正值和负值会向相反方向弯曲。
3. 设置 `弯曲过渡宽度`。数值越大，缓入和缓出跨过的列越多，弯曲越平缓；默认是 4 格。
4. 选择是否勾选 `弯曲后平滑回正`：
   - 勾选：先逐渐弯入，再平滑回到原方向。
   - 不勾选：逐渐弯到目标幅度，并在弯曲区后方继续保持，直到模型边缘；整体会表现为单向斜坡。
5. 点击 `弯曲选择`。
6. 在网格上按住涂抹需要弯曲的列；按住 Alt 涂抹可以擦除。
7. 再次点击按钮退出弯曲选择，然后生成。

弯曲会在选区两侧自动加入缓入、缓出区域，并使用平滑曲线逐列增加和减小偏移，不会在选区边界突然折弯。方块模式和混合模式中的内部方块、三角外壳都会使用同一弯曲方向；生成后仍会自动选中整组。

## 局部宽度

1. 设置 `局部宽度倍数`：大于 1 会加宽，小于 1 会收窄。
2. 设置 `宽度过渡宽度（格）`，控制选区两侧的平滑过渡范围。
3. 点击 `宽度选择`，在网格上涂抹需要调整的列；按住 Alt 可擦除。
4. 再次点击按钮退出宽度选择，然后生成。

宽度选区会沿着模型横向平滑拉伸或收缩，不会直接截断。开启左右对称时，宽度选区也会自动镜像。`清除宽度` 可以取消全部宽度选区。

## 按位置设置方块或三角形

生成方式选择 `按位置混合（方块/三角）`：

1. `按位置混合：默认部位` 一般选择 `默认方块`。
2. `部位选择：标记为` 选择 `三角形`，点击 `部位选择` 后涂抹刀刃边缘。
3. 按住 Alt 可擦除部位标记。
4. 点击 `清除部位` 可取消全部部位标记。
5. 生成后，未标记格子是方块，标记为三角形的格子使用三角面，适合制作方块刀身与三角刀刃。

也可以把默认部位设为三角形，再单独把指定位置标记为方块。部位标记支持左右对称、弯曲和局部宽度。

相邻的三角形部位会先合并成一个连续区域，再整体生成三角面。两个三角格会共享边或表面，不会各自闭合后只在一个顶点相碰，因此更适合连接成刀刃。

## 格式限制

Java Block/Item 的导出格式只包含 cuboid，不包含任意三角网格。插件会在 Java Block/Item 中禁用三角形和混合模式，避免形状在 Blockbench 中可见、导出后却消失。

因此 Java Block/Item 的纯方块模式仍会保留方块轮廓；需要圆润外形时，应使用 `Generic Model / Free Model` 的三角形或混合模式。

需要三角面或混合模型时，请新建 `Generic Model / Free Model` 项目，再使用 OBJ、GLTF 或项目自身支持的导出方式。

## 建议

- 画宽一些、围住至少一格，太细的线条可能没有可填充面积。
- 方块模式默认合并相邻格子，能显著减少组件数量。
- 完成后可在 Blockbench 中继续移动、旋转、缩放、赋纹理或制作动画。
